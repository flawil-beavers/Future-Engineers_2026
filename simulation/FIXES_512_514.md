## Delivered source changes

1. `Vision::processComponent` keeps the nearest valid upright RED/GREEN
   component separately from the largest raw component. A large rejected wall
   or floor region can no longer suppress a smaller disconnected valid pillar
   before acquisition. Raw components remain available for diagnostics and
   occupancy checks. The exact existing shape gate is shared through
   `include/obstacle_blob_validation.h`; HSV thresholds and shape limits have
   not been widened. Connected wall/pillar merges still rely on the existing
   mapped-seat silhouette fallback. The component masking weakness is proven
   by synthetic images; it is not claimed as the uniquely proven image-level
   cause of512/514.
2. A rejected/unassociated low upright colour region vetoes EMPTY evidence
   even if its bearing disagrees with the estimated seat. This protects the
   edge GREEN of512 and oversized GREEN of514. Shallow high room strips and
   sufficiently distant regions remain nonblocking. Existing UNKNOWN holds
   and observation recovery remain in use; uncertain colour is never invented.
   The cached discovery trace raw-block bit now includes this veto.
3. The existing70mm ambiguity band between the two rails now applies at all
   distances, including the GREEN silhouette fallback. Previously it only
   applied beyond700mm, allowing514's ambiguous547/522mm RED views to latch.
   A close valid unassociated object commands zero speed until usable evidence
   arrives. The400mm range gate also requires a real low ground foot; the
   synthetic170mm distance assigned to distant edge-clipped blobs is not
   accepted as proximity evidence by itself. This does not independently
   measure pose or guarantee every object remains detected across dropouts.
4. Five exit segments and their directions/steering remain. First four lengths
   are now30/36/26/84mm, rebalanced for513's start and independent curvature
   variation by segment. Final alignment still uses the existing gyro target
   and120..220mm travel bounds. The CW current-pose barrier guard remains
   enabled with its5mm face reserve. Braking must reach measured speed<=5mm/s
   before steering reversal; failure to settle within dwell+2.5s holds with
   `exit_brake_not_settled`. After steering preload, measured motion restarts
   the200ms settling dwell; the next travel baseline is captured afterwards.
   Persistent invalid/moving encoder readings can therefore keep drive off.
